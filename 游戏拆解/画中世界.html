《Gorogoa》——《画中世界》关卡拆解分析案

游戏类型：2D 点击解谜 / 叙事向 · 开发团队：Buried Signal（Jason Roberts 单人开发） · 发行时间：2017年12月 · 平台：Steam / Switch / iOS / Android · 时长：约 1.5–2 小时

一、简要介绍

《画中世界》是一款玩法很独特的二维点击类解谜游戏，屏幕中只有四个格子，每个格子里面是一个场景，玩家通过移动、缩放、重叠画面，让场景产生关联，从而破解谜题。

它的剧情带有一定的宗教元素，和安静的游戏节奏、美术风格结合得很好，此外，我们还能从画面中注意到一些反战的内容。游戏并没有向我们讲述一个条理清晰、细节完整的故事，我们所能明确的大概内容就是：一个男孩在城中看到了一种奇幻生物，就是标题gorogoa。他从书中读到，想再见到gorogoa需要集齐五色果实，从此他踏上了寻找果实之旅。

整个故事像它的解谜一样被拆开，分散在整个游戏流程中，需要玩家自己一点一点拼凑出来，这也让游戏本身有了更多的解读。

二、叙事与美术风格

题材：奇幻、成长、追寻、记忆

  • 纯手绘：Jason Roberts 花了五年时间，手绘了数千帧动画。结合画面上的纸纹底和浅淡的图案，使整个游戏的艺术感更加强烈，给玩家一种在翻阅旧书的既视感。
  • 多层透视：画面中的场景不是单一平面，而是多层嵌套的"画中画"。前景、中景、背景可以分别移动、缩放，形成视觉错位。
  • 色彩风格：游戏整体色调都是低饱和的，符合其安静的风格基调。然而在涉及幻想生物gorogoa及与之相关的场景时，作者反而选择了大片的红与绿等高饱和颜色绘制它，将其突出，更凸显了它的“幻想”感。
  • 细节密度高：每一格画面都蕴藏了大量细节，暗示着故事剧情。而重点可交互的类型则被作者用光圈提示，避免玩家被扰乱从而卡关。

四、核心玩法说明

机制一：移动与缩放

玩家可以拖动四个画面中的任意一个，也可以缩放它。移动和缩放不是"操作"，是"叙事"——每移动一次画面，就是主角在翻过人生的某一页。

设计要点：让核心操作同时承担玩法和叙事两个功能。

机制二：视觉连接

当两个画面的元素在屏幕上对齐时，它们会产生连接。果实缩小后变成太阳，太阳照亮下一个画面，画中的门通向新场景。视觉上的连接，对应叙事上的因果。

设计要点：视觉连接要同时满足"看起来合理"和"叙事上合理"。

机制三：无文字引导

游戏没有任何文字提示。玩家怎么知道该移动哪个画面？靠的是构图暗示——需要连接的两个元素，会在屏幕上形成明显的视觉指向。一条线的延伸、一个形状的缺口、一个颜色的呼应。

设计要点：用构图代替教程。如果玩家需要文字才能理解，说明画面没有说清楚。

五、目标受众与平台

目标受众：

  • 喜欢解谜游戏的玩家（《锈湖》《纪念碑谷》《笼中窥梦》的玩家）
  • 喜欢艺术性强的独立游戏的玩家
  • 对叙事向游戏感兴趣的玩家

平台选择：

  • PC（Steam）为主，适合大屏体验画面细节
  • Switch / 移动端为补充，适合碎片化游玩
  • 游戏时长短（1.5–2 小时），适合移动端

六、主要玩法说明

以第一章第一个谜题为例。

玩家看到什么：

  • 第一格：男孩在房间里，看着窗外一只鸟
  • 第二格：窗外有一只鸟飞过，衔着一个果实
  • 第三格：果实落在地上

玩家怎么解：

  1. 拖动第一格，让男孩的视线对准第二格的鸟
  2. 缩放第二格，让鸟嘴里的果实变大
  3. 果实从画面中掉出，落到第三格
  4. 男孩捡起果实，果实变成太阳，照亮下一个场景

为什么这个设计好：

  • 操作简单：只需要拖动和缩放
  • 逻辑清晰：果实 → 太阳 → 照亮，因果关系明确
  • 叙事自然：男孩追寻 Gorogoa 的旅程从一颗果实开始
  • 无文字：玩家看一眼就知道该做什么

难度递进：

  • 第一章：一个连接（果实 → 太阳）
  • 第二章：两个连接（太阳 → 门 → 新场景）
  • 第三章：三个连接，且需要先缩放再移动
  • 第四章：多个连接，且需要组合不同画面的元素

每一章只增加一个变量，玩家不会感到挫败，但也不会觉得无聊。

七、叙事与玩法的耦合

这是《画中世界》最值得学的地方：它的叙事不是"讲"出来的，是"拼"出来的。

游戏讲的是一个男人从童年到老年的追寻。但玩家不是在看故事，是在拼故事。每移动一次画面，就翻开一段人生。每连接两个场景，就建立一段因果。玩家拼完四个章节，故事就完整了。

叙事结构：

  • 表层：移动画面，连接场景，解谜
  • 中层：四个章节，对应四段人生
  • 深层：一个人用一生追寻一个幻影，最后发现追寻本身就是意义

三层同时推进，玩家在解谜的同时，不知不觉地拼出了整个故事。没有一句旁白，没有一段文字，但玩家玩完会记住这个故事。

八、可迁移的设计原则

  1. 核心操作即叙事：不要让玩家"点下一步"来看剧情。让玩家通过核心操作（移动、缩放、拼接）来推进叙事。
  2. 构图代替教程：如果玩家需要文字才能理解，说明画面没有说清楚。
  3. 每一关只加一个变量：难度递进不是"加更多谜题"，是"加一个变量"。
  4. 视觉连接要有叙事含义：不只是"看起来连上了"，要"叙事上说得通"。
  5. 短小精悍：1.5–2 小时，不注水。玩家玩完觉得"刚刚好"，而不是"怎么还没结束"。

九、对我项目的启发

《画中世界》和我的项目《书里窗外》有很多相似之处：都是 2D 视觉错位解谜，都是无文字引导，都是叙事与玩法耦合。不同之处在于：

  • 它是四个画面移动缩放，我是书页与窗外的联动
  • 它讲的是男人的一生，我讲的是女孩的濒死幻想

我可以借鉴的：

  • 让核心操作承担叙事功能：翻页 = 写故事，拖拽 = 帮她解谜
  • 用构图暗示代替文字教程：书页上的元素位置、颜色、大小，暗示玩家该做什么
  • 每关只加一个变量：第一关平移，第二关缩放，第三关遮挡
  • 结尾要收束：埃拉拉到风眼，在书上写下最后一句，告别
  • 时长控制：我的游戏也控制在 30–60 分钟，不注水
