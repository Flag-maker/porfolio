核心项目

独立开发中的 2D 点击解谜剧情向游戏。按系统、关卡、叙事三个方向整理。

项目概述

《埃拉拉》（暂定名）

2D 点击解谜剧情向 · Godot · 独立开发

玩家在书页中操作道具，窗外现实随之改变。核心玩法是利用视觉错位，把逻辑上不相连的平面在特定视角下连接起来，让角色通过。

核心循环：桌前观察 → 进入书中操作 → 全局状态改变 → 窗外场景变化 → 退出查看 → 利用错位解开谜题 → 推进剧情。

我的职责：策划、关卡设计、叙事架构、系统设计、程序实现。

  • 核心循环
  • 视觉错位

  • 纸面原型
